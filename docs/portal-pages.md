# صفحه‌های پورتال و اخبار تصویری

## صفحه‌ی اصلی (`/Portal`)

ترتیب بخش‌ها: سربرگ ← کارت کوچک «کارتابل نظارت» (فقط برای ناظر و بررسی‌کننده) ← **اخبار و اطلاعیه‌ها** ← سامانه‌های من ← پیوندهای سریع.

- **اسلایدر اخبار** (`wwwroot/js/news-carousel.js`): کارت تصویری با نوع، عنوان، خلاصه‌ی دوخطی و تاریخ. هر ۶ ثانیه روی کارت بعدی متمرکز می‌شود. با hover، فوکوس صفحه‌کلید یا پنهان‌بودن تب مکث می‌کند و با `prefers-reduced-motion` خودکار حرکت نمی‌کند. فقط track افقی جابه‌جا می‌شود و صفحه پرش نمی‌کند.
- مطلب بدون تصویر با زمینه‌ی رنگیِ نوع مطلب (خبر، اطلاعیه، بخشنامه) نمایش داده می‌شود.
- مدال «درخواست دسترسی» (کارت سامانه‌های من) فقط فرم را دارد؛ پیگیری درخواست‌ها در `/AccessRequests` است.

## صفحه‌های داخلی (پوسته‌ی `_LayoutPortal`)

| مسیر | محتوا |
|---|---|
| `/Account/Profile` | مشخصات و اطلاعات حساب |
| `/Account/Settings` | تغییر رمز (پس از موفقیت خروج و ورود دوباره)، وضعیت امنیت ورود، خروج |
| `/Account/Security` | راه‌اندازی Google Authenticator |
| `/Notifications` | همه‌ی اعلان‌ها (سامانه‌ها + هشدار درخواست دسترسی) با صفحه‌بندی سمت سرور، تب همه/خوانده‌نشده/خوانده‌شده با شمار، فیلتر منبع و بازه (۲۴ ساعت، ۷، ۳۰ و ۹۰ روز)؛ «خواندن همه» |
| `/Supervision` | کارتابل نظارت (فقط‌خواندنی): درخواست‌های سامانه‌های تحت نظارت با تب وضعیت و شمار، فیلتر سامانه و صفحه‌بندی؛ برای بررسی‌کننده پیوند «بررسی در پنل مدیریت». در منوی حساب فقط برای ناظر |
| `/AccessRequests` | ثبت درخواست دسترسی و پیگیری/لغو درخواست‌های من با تب وضعیت |
| `/Library` | قوانین و مقررات، انتشارات و پشتیبانی، فرم‌های سازمانی: تب هر بخش با شمار، جست‌وجو (ی/ک عربی، نیم‌فاصله و ارقام فارسی یکسان)، نتیجه به تفکیک بخش؛ تب «همه» بدون جست‌وجو از هر بخش فقط ۶ مورد و پیوند «مشاهده‌ی همه‌ی … مورد» به تب همان بخش را نشان می‌دهد؛ برای ناشناس هم باز است. داده در `Pages/Library/LibraryCatalog.cs` (تا اتصال به API فرم‌ها و اسناد در فاز ۳) |
| `/Publications` | همه‌ی مطالب: تب نوع (خبر، اطلاعیه، بخشنامه)، جست‌وجو، کارت تصویری و صفحه‌بندی؛ برای ناشناس هم باز است |
| `/Publications/Details/{id}` | سربرگ با نوع و تاریخ، تصویر شاخص، متن و ستون «مطالب دیگر» (با همان دامنه‌ی دید) |

هدر مشترک (`ViewComponents/PortalHeaderViewComponent`) شمار اعلان‌های خوانده‌نشده و منوی حساب را دارد؛ موارد منو در `_PortalUserMenuItems` با صفحه‌ی اصلی مشترک‌اند. سبک‌ها: `wwwroot/css/portal-shell.css`.

## تصویر شاخص مطالب

- مدیر در «اطلاع‌رسانی سازمانی ← ویرایش» تصویر JPEG، PNG یا WebP تا ۲ مگابایت بارگذاری یا حذف می‌کند و پیش‌نمایش کارت را می‌بیند.
- نوع فایل در API از روی امضای فایل تشخیص داده می‌شود (SVG و سایر نوع‌ها رد می‌شوند). پاسخ تصویر `nosniff` دارد.
- دید تصویر همان دید مطلب است: ناشناس فقط مطلب عمومی، کاربر واردشده مطلب منتشرشده، مدیر همه (`api/public|api|api/admin/publications/{id}/image`). Portal و Admin تصویر را از API می‌گیرند و به مرورگر می‌دهند (`/Publications/Image/{id}` و `/Admin/Publications/Image?id=`).
- نشانی تصویر نسخه‌دار است (`?v=`)؛ کش خصوصی مرورگر یک روز.

## آزمون‌ها

`Integration/PortalPagesTests.cs` — تشخیص نوع تصویر، دید تصویر، بارگذاری از پنل مدیریت و نمایش در اسلایدر، پوسته‌ی صفحه‌های داخلی، تب‌های اعلان، هدر و منوی پنل مدیریت.

## پیام‌ها (توست)

- پورتال: `wwwroot/js/portal-toast.js` و `css/portal-toast.css` — توست وسط بالای صفحه با رنگ‌های تم. پیام سرور با partial `_PortalToasts` (عنصر پنهان `data-toast`) نمایش داده می‌شود و خطاهای `asp-validation-summary` هم خودکار توست می‌شوند. در درخواست دسترسی از مدال، موفقیت مدال را می‌بندد و توست موفقیت نشان می‌دهد؛ خطا توست خطا می‌دهد و مدال با مقادیر واردشده دوباره باز می‌شود.
- پنل مدیریت: `app-toast.js` (توست تمپلیت yzen) علاوه بر `_ToastMessages`، همه‌ی خطاهای `asp-validation-summary` و خطای صفحه‌ی ورود را هم توست می‌کند.
- هدر پوسته برای بازدیدکننده‌ی ناشناس دکمه‌ی «ورود به حساب کاربری» با بازگشت به همان صفحه دارد.

## مرکز اعلان و کارتابل نظارت (API)

- `GET api/portal/notifications/page?kind=system|request&status=unread|read&days=1|7|30|90&page=` اعلان سامانه‌ها و هشدار درخواست را با UNION ALL در بانک مرتب و صفحه‌بندی می‌کند (۲۰تایی). شمار تب‌ها (`AllCount`، `UnreadCount`) با همان فیلتر منبع و بازه است. فیلتر نامعتبر ۴۰۰ می‌دهد. دید هر منبع همان دید فهرست‌های جداگانه است (`NotificationQueries.Visible`، `SupervisionQueries.Alerts`). شمار زنگ هدر پوسته هم از همین endpoint است، پس دیگر به ۵۰ مورد آخر محدود نیست.
- `GET api/portal/supervision/inbox?status=&applicationId=&page=` و `GET api/portal/supervision/inbox/summary?applicationId=` (سامانه‌های تحت نظارت و شمار به تفکیک وضعیت). سامانه‌ای که کاربر ناظرش نیست، فهرست خالی برمی‌گرداند.
- صفحه‌ی `/AccessRequests` هم فیلتر وضعیت را به API می‌فرستد؛ قبلاً فقط ردیف‌های صفحه‌ی جاری فیلتر می‌شد.
- آزمون‌ها: `Integration/NotificationCenterTests.cs` و `Database/LiveNotificationCenterTests.cs` (اجرای همان کوئری روی SQL Server، فقط‌خواندنی).

## صفحه‌های خطا

- پورتال و پنل مدیریت هر کدام یک صفحه‌ی `Error` دارند (`/Error/{code}`) برای ۴۰۳، ۴۰۴ و ۵۰۰، با تم همان پرتال: پورتال سرمه‌ای/طلایی، پنل مدیریت تمپلیت yzen. متن هر کد در `shared/UI/ErrorPageContent.cs` است و هیچ جزئیات فنی نشان داده نمی‌شود؛ برای ۵۰۰ شناسه‌ی پیگیری نمایش داده می‌شود.
- `UiHost` پاسخ‌های بدون بدنه (مسیر ناموجود، `NotFound()` صفحه‌ها) را با `UseStatusCodePagesWithReExecute` به این صفحه می‌برد. مسیر `/Account/AccessDenied` هم همین صفحه با کد ۴۰۳ است (قبلاً متن ساده بود). خطای پردازش‌نشده در محیط غیرتوسعه به `/Error` می‌رود.
- این صفحه از layout ورود استفاده می‌کند و API را صدا نمی‌زند، تا وقتی API در دسترس نیست هم نمایش داده شود.
- آزمون‌ها: `Integration/ErrorPagesTests.cs`.

## پیام‌های صفحه‌ی ورود پورتال

خطای ورود، پیام خروج و پیام‌های فرم (`wwwroot/js/login-form.js`) با توست هم‌تم پورتال نمایش داده می‌شوند. اگر `window.portalToast` نباشد (پنل مدیریت)، توست تمپلیت yzen استفاده می‌شود. بدون JavaScript، همان کادر پیام قبلی در `<noscript>` نمایش داده می‌شود.

## موبایل: پنل اعلان و منوی حساب

در عرض کمتر از ۹۶۰ پیکسل، پنل اعلان و منوی حساب صفحه‌ی اصلی `position: fixed` و وسط صفحه‌اند. قبلاً absolute بودند، به سمت چپ از صفحه بیرون می‌زدند و حتی در حالت پنهان صفحه را ۱۲۵ پیکسل به‌صورت افقی اسکرول‌پذیر می‌کردند.

## بخش «قوانین، انتشارات و فرم‌ها» در صفحه‌ی اصلی

سه ستون پیش‌نمایش با یک دکمه‌ی «مشاهده‌ی همه» برای کل بخش که به `/Library` می‌رود؛ هر مورد به نتیجه‌ی خودش در همان صفحه پیوند دارد. دکمه‌های «همه»ی هر ستون و پنجره‌های جست‌وجو حذف شدند. آزمون‌ها: `Integration/LibraryTests.cs`.
